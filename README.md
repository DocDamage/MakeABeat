# Lost Samples Desktop

A native Rust recreation of the [Lost Samples](https://www.lostsamples.com/) digging and beat-making workflow. The app runs locally with an egui interface and CPAL audio output.

## Run on Windows

Open `target/release/lost-samples-desktop.exe`, or build and run it from source.

```powershell
cargo run --release --locked
```

## Make a flip

1. Select one or more genres and click **Dig a record** to find a YouTube record and open it in the studio. **All** lets the app pick a genre. **Dig another** uses the same filters from the studio. The source picker also offers Wikimedia Commons, demo records, and a local folder. **Import audio** and drag-and-drop accept WAV, MP3, FLAC, Ogg Vorbis, M4A, and AAC files.
2. Click the studio waveform to seek, or drag across it to set **In** and **Out**. Drag either green handle to trim that edge. Use **+**, **−**, or **Zoom to selection** for detail, then drag the overview to pan. **Fit** shows the whole record. **Slice selection** divides the range evenly, by beat, or near transients. Pressing an empty pad adds a marker at the playhead. Use the selected pad inspector to assign a range or edit independent boundaries.
3. Open **Sequence**, select a pad and place it on the **Chops** row. Paint drum hits or open **Sequence tools → Drum templates**. Hold **Shift** for accents or **Ctrl-click** to edit a step’s velocity. Patterns can span up to 16 bars. Use **Sequence tools → Edit bars** to change the length, copy, paste, insert, duplicate, or remove a bar.
4. **Project → Save project** creates a portable `.flip` file with the source audio, named samples, and edit settings. **Export** can render the current pattern or arrangement as WAV, MIDI, or a DAW pack. WAV options include 44.1, 48, or 96 kHz, 16 or 24-bit PCM, 32-bit float, and up to 10 seconds of tail. An enabled loop plays under the pattern when it has no sequenced chops. **Export → MIDI** writes drum notes on channel 10 and chop triggers on channel 1, starting at C1.

Use the status area to follow background stages and render progress. **Cancel job** stops at the next checkpoint. When an operation fails or is cancelled, **Retry last operation** uses the same settings and destinations. Exports keep existing files in place until publishing starts.

The fixed transport controls source, pattern, and song playback from any workspace. Open **Help** or press **Ctrl+K** to search commands and shortcuts and adjust UI scale, control contrast, and motion. **Sample** holds the waveform and saved cuts, **Perform** shows pads or keys, and **Sequence**, **Arrange**, and **Mix** have dedicated views. In Sample, **Pads & keys** opens the pad inspector and **Sample tools** opens one analysis or setup tool at a time. Drag the divider to resize the inspector on wide windows. On smaller windows, the inspector opens below the waveform. Tab moves between controls, Enter or Space activates the focused control, and Escape clears focus or closes the dialog.

**Ctrl+S** updates the opened project after the first save. **Ctrl+Shift+S** saves a new copy. If a source switch or quit would replace unsaved work, choose Save, Discard changes, or Cancel. The app periodically keeps a recovery snapshot for unsaved edits and offers it on the next launch after an interrupted session. **Ctrl+Z** and **Ctrl+Shift+Z** undo and redo project edits across the Studio.

Use **Sample → Add audio source** to bring more recordings into the same project. Use the source picker to edit each waveform. Pad ranges, key assignments, custom drum sounds, and saved cuts remember which source to play. The project file embeds the audio for all project sources.

In **Sample → Sample tools → Beat map**, analyze up to three minutes of the current source or add beats at the playhead. The built-in pulse estimator runs locally without Python. Blue waveform marks are suggestions. **Use analysis** saves them to the project. Set the first downbeat, move or remove individual beats, and use **Half tempo** or **Double tempo** to correct the interpretation. Reanalysis keeps user anchors and respects removed beats. Use **Slice selection → Beats** or **Bars** to cut on the confirmed grid. Set suggested phrase starts from the bar grid, then add or remove starts manually.

**Sample tools → Warp & fit to bars** and **Preview warp from beat map** prepare pitch-preserved previews. Compare the original with the processed audio, then choose **Keep as new source** to embed the preview. The project stores its source and warp settings. Every segment must fit between 0.5× and 2× its original duration. **Edit bounds and markers** transfers the preview’s positions to the manual editor.

In **Sample → Sample tools → Groove transfer**, select one to eight complete bars on the corrected beat map and choose **Extract from selected break**. **Adjust extracted anchors** lets you edit each sixteenth-note offset and accent. Save a named groove in the project, or export a `.groove` file to use it in another project. A groove file contains the timing, accents, and source details.

Open **Groove transfer** under **Sample tools** or **Sequence tools** to set separate **Timing** and **Velocity** strengths and choose lanes. **Play before** and **Play after** loop the working pattern for comparison. **Apply groove** writes the changes in one undo step. Alt-click a programmed hit to edit its offset under **Step conditions**. Programmed hits follow the existing swing and lane timing, plus their own offset of up to 30 ticks. To transfer a groove to a recorded pad or key performance, select its lane and turn on **Include recorded hits**.

In **Queue**, or under **Cut actions** for a saved sample, choose **Audition with beat**. The preview joins on the next bar while the beat plays. Use **Play beat** if the transport is stopped. A complete beat map sets the loop’s downbeat and length. Otherwise, choose how many bars the cut contains. Switch between **Original** and the pitch-preserved **Fit** at the next bar, and adjust **Preview** to set its level independently. If the requested fit exceeds the stretch limits, the preview plays at original speed. When following external MIDI clock, the preview uses original speed and stops on reposition. Choose **Original** to rejoin on the next bar.

For the optional neural beat tracker, open **Beat This! setup** and select an isolated Python environment with CPU PyTorch and `beat-this==1.1.0`. Choose **Check environment**, then **Download verified weights**. The 8.1 MiB checkpoint is cached locally and analysis runs offline after setup. [Worker setup and protocol](workers/audio_analysis/README.md)

Select an isolated bass or melodic passage, then choose **Sample tools → Transcribe → Transcribe to notes**. You can also use an existing stem as the source. Set the note range, minimum duration, onset threshold, and frame threshold. The preview follows the corrected beat map when one is available. Otherwise, enter a source tempo and choose whether the selection or first note starts the phrase. Use **Hear source** and **Hear notes** to compare, and edit the candidates in the piano roll before choosing **Create pattern**. Phrases longer than 16 bars are split into linked patterns and added to the arrangement. [Basic Pitch setup](workers/audio_analysis/README.md#basic-pitch-transcription)

The note preview can use a built-in sine tone, the Studio chromatic sample, or a saved cut with a root note. **Piano roll → Transcribed phrase sound** changes the instrument across linked patterns while retaining note timing. WAV renders keep bends. In MIDI and DAW pack exports, **Per-note MIDI bends** uses up to 13 simultaneous bend channels with a ±12-semitone range. Choose **Quantized pitch** for a single keys channel or if the destination cannot use separate bend channels. Quantized pitch rounds the note’s initial pitch to a semitone. Live MIDI uses the standard keys channel.

**Sample → Sample tools → Record audio input** selects a microphone or line input, shows the peak meter, and optionally monitors the input on the selected output. Start a recording and use **Finish input** to add it as an embedded source. A take can last up to five minutes. **Sample → Sample tools → Stem separation** can add vocals, drums, bass, and other as four sources using a local [Demucs installation](https://github.com/facebookresearch/demucs). Choose the executable or put it on PATH. The first run may download model weights. Cancel from the status bar to discard the separation job.

Under **Sequence**, **Resample pattern to pad** renders one pass into the next empty pad and makes the result available in Sample. Use **Resample selected pad** in the pad inspector to render that pad's settings, or **Resample song to pad** in Arrange to render the arrangement. In **Mix → Drum channels**, select a project source for a drum lane, adjust its level, pan and tuning, or audition, mute, and solo it. Use **Save drum kit** to save the strips, drum effects, and assigned source audio in a reusable kit. **Load drum kit** imports those settings and sources into the current project. **Mix → Audio output** selects the playback device, rate, and requested buffer size. **Project → Save as template** stores a reusable copy with its audio and arrangement. **New from template** opens it as an untitled project.

In **Perform**, choose **Chromatic sample** to play one waveform selection across the keyboard. Set its root note to the key that should play at the sample’s original pitch. Switch back to **Chops per key** to use the individually assigned cuts. In Chromatic sample mode, choose a scale to highlight its notes or constrain playing to that scale. Chord controls play a diatonic triad or seventh from one key. The arpeggio tool writes the selected notes to the pattern.

In **Samples**, use **Save selection** to name and keep a cut. **Select** recalls its range on the waveform, **Play** auditions it once, and **WAV** exports it. To revise a saved cut, select it, trim the range, and click **Update saved cut**. Search by cut name or source title. Mark cuts to number or export them together. **Cut actions** shows matching pad assignments and key overrides and lets you assign the cut to the selected trigger. Switch on **Stereo channels** above the waveform to see left and right separately. **Move or copy pad** moves or swaps assignments and sound settings while sequencer steps retain their pad numbers. When working in an opened project, use **Save project** to keep changes to its cuts.

Switch between **16 pads** and **88-key chop piano** in Studio. The piano plays sample chops. Keys C4–D♯5 mirror pads 1–16 by default, and every key from A0 through C8 can have its own chop. Select a key and use **Assign selection**, **Copy pad chop**, or **Copy named cut**. **Assign next key** assigns the waveform selection to the next key you play. Both views offer gain, pan, tuning, reverse, attack and Gate release for the selected trigger. Use the sequencer’s **Keys** row to place the selected key on a step. DAW packs include raw key chops and MIDI on channel 2 for sequenced keys. Save a project to keep the key assignments, steps and controls.

Open **MIDI devices** in Studio to view connected inputs by name, choose whether each plays piano keys or pads, and use **MIDI Learn** for buttons, absolute CC controls, or relative encoders. The device dialog also offers input channels, velocity curves, soft takeover, and mapping import/export. Learned controls stay with the port. The Novation Launchkey MK4 profile maps its standalone drum pads and Start/Stop buttons. Standard input handles note velocity, sustain in piano Gate mode, pitch bend for keys, channel volume (CC7), and brightness (CC74). Check **Follow clock from this input** on one port to sync tempo, sequencer steps, and transport to incoming MIDI clock. Select a destination under **MIDI output** and apply it to send pad notes on channel 1, key notes on channel 2, and drums on channel 10. Enable clock sending to sync external gear to internal playback.

In the sequencer, choose **Quantize Off**, **1/8**, **1/16**, or **1/32**, then press **Record** and play the pads or keys with the mouse, computer keyboard, or MIDI. Record starts or overdubs the loop. When following external MIDI clock, Record arms the sequencer for the external transport. Use **MIDI Learn → Toggle recording** to bind a hardware record button. **Off** keeps the timing between steps, while grid settings snap the start of new hits. Enable **Click** for a metronome. **Sequence tools → Recording options** sets click level, count-in, whether to replace previously recorded notes, and the bars eligible for new notes. Choose **Finish recording** to keep listening or **Stop** to stop the sequencer. Gold dots show captured hits. Right-click a cell to clear its hits, or use project **Undo** to reverse a recording take. Takes are included in project saves and WAV and MIDI exports.

In **Studio → Perform**, use **Capture last…** after playing pads or keys with Record off. Choose 4, 8, or 16 bars, check the alignment preview, and use **Capture to new pattern**. With the transport stopped, the first retained hit starts the pattern if it fits within the requested window. Quantize is optional. Capture keeps velocity and sustained gate lengths. The preview flags omitted pitch bends and history lost to overflow.

Set a **Choke** group in the pad sound controls or in **Mix → Drum channels**. Hits in the same group cut one another off with a short fade, including across pads and drums. For simultaneous programmed hits, drum channels trigger after the pad and follow their displayed order. Recorded pad hits at that tick trigger after the programmed hits. Choke articulation is included in WAV and rendered stems.

Open **Sample layers** in a pad, assigned key, or chromatic instrument’s sound controls. The original assignment is the base layer. Add up to three layers with their own source ranges, gain, pan, tuning, and velocity ranges. Overlapping ranges play together. Disjoint ranges select different layers at different velocities. A processed cut uses the highest playable velocity.

In the chromatic instrument, enable **Mono / legato** to play the most recent held or sustained key. Releasing it returns to the previous active key. **Glide** sets the pitch transition in milliseconds. **Retrigger overlapping notes** restarts the sample. With retrigger off, matching layers continue from their current playback positions.

In **Sequence → Sequence tools → Drum templates**, browse 89 editable drum templates by genre, style, or length. Boom bap and trap each have 17 single bars and six 2- or 4-bar phrases with variations and fills. The browser plays the full phrase with the current kit and lets you inspect each bar. Applying a template replaces the drum hits and conditions starting at the selected bar and extends the pattern when needed, up to 16 bars. Turn on **Use suggested tempo and swing** to preview and apply the template’s timing.

In **Sequence**, turn on **Select cells** to drag across lanes and steps. Open **Sequence tools → Edit cell selection** to set the corners with the keyboard or copy, cut, or clear the selected cells. Paste uses the upper left of the new selection as the destination and replaces its contents. Copied cells carry velocities, step conditions, and recorded pad or key hits. Open **Sequence tools → Lane timing** with playback stopped to advance or delay programmed hits by up to 30 ticks per lane. Audio playback, live MIDI, and exports use the same offsets. Each hit stays in its bar, and recorded hits keep their captured timing.

Use **Sequence tools → Generate variations…** to audition four candidates against the original. Lock whole lanes or select a rectangle before opening the dialog to lock its cells. Selecting one cell locks an individual hit. Set density, variation, and fill chance, and keep the seed to reproduce a candidate. **Keep as new pattern** saves the named version in one undo step.

Select a programmed step under **Step conditions**, or select a single piano roll note, to open **Hit sound…**. Pitch is relative to the instrument in cents. Start offset skips a percentage of the assigned range in the playback direction. An optional low-pass cutoff is set in hertz. Each trigger has its own settings. WAV renders include them, and MIDI retains the trigger and its timing.

On Windows, open **Export → Drag WAV** to prepare a raw waveform cut, processed pad, or current pattern. Drag the ready WAV into your DAW. The file stays in the application’s export folder for DAW sessions that reference it. Use **Reveal in folder** to locate it, and **Delete export…** after the file is no longer needed.

Use **Snapshots…** in Studio to save a named state for A/B comparison. Select a pattern or song and a bar present in both states, then prepare the comparison. **A · Working** and **B · Snapshot** each restart at that bar. **Match levels** attenuates the louder preview to match the quieter one. Stop playback before restoring a snapshot. Restore and Delete can both be undone, and snapshots share the project’s embedded audio.

After recording, open **Piano roll** in the sequencer and choose **Pads** or **Keys**. Click, Shift-click, or drag an empty area to select hits. Drag selected hits to change timing or move them to assigned lanes. Left and Right nudge by one tick, or ten with Shift. Drag a Gate note’s right edge to change its hold length. Use **Apply velocity** or **Delete** on the selection. Choose a grid and click **Quantize selected** to snap only the selected starts. Hits that would collide on the same lane keep their timing. The piano roll includes programmed pad and key steps as well as recorded hits. Project **Undo** reverses piano roll edits.

Use **Draw** to add a hit by clicking an empty spot on an assigned lane. **Snap draw** places hits on the chosen grid. Turn it off to place hits between grid lines. To duplicate notes, select them, press **Ctrl+C**, choose a destination bar, and press **Ctrl+V**. **Add bar** extends the pattern when you need a new destination. Pasted notes keep their offsets from the source bar, velocity, and hold length. The velocity strip and numeric note properties are available for selected notes. **Step conditions** sets chance, repeats, eligible passes, and whether a step plays during a Fill. Exports use the same step rules with Fill off. Paste skips occupied positions.

Open **Studio → Arrange** to build a full beat. Name your working pattern and click **Save current as new**. Use **New blank** for an empty grid or **Save current as new** again to make a variation from the current grid. Add Intro, Verse, Hook, Bridge, or Outro sections and assign a pattern to each. Drag a section block to reorder it, or select it and click **Duplicate** to place a copy after it. Drag either edge to trim or extend by whole bars. Sections close up as you edit, and extensions loop the linked pattern. Editing a named pattern updates all sections that use it. Use **Make unique** to give a selected section its own copy. Patterns share the project's tempo, kit, and sample assignments. **Play song** previews the whole timeline. Use **Play from section** or **Loop section** when working with a selected section. Save the project to keep the patterns and arrangement. WAV, MIDI, and DAW exports follow the timeline. In **Scene launcher**, launch saved patterns on quantized bar boundaries using the internal clock. Turn on **Capture played bars** to collect completed bars, then append them as linked sections.

With the song stopped, open **Automation** in Arrange. Choose **Master volume** and draw from 0% at the start to 100% at the end of the intro. Use the sample and drum volume lanes to fade them separately, or draw a build with mix low-pass, delay, and reverb. Click to add a point, drag a point to move it, or right-click to remove it. Choose a point shape or enter its position and value numerically. Use **Write automation** to capture changes made to the live value during song playback. Curves stay at their song positions when sections move. They save with the project and render into the WAV mix and DAW audio stems.

To have a curve move with a section, select the section and choose **Section** in Automation. Draw directly on that section or choose **Link lane to section** to move that part of the current song lane into it. A section curve overrides the song lane for the same control while that section plays. **Duplicate** copies the section's curves so you can edit either copy independently.

To reuse curves on a different section, choose **Copy automation** in Section mode and select the destination block. **Paste to fit** stretches or shrinks the curves in proportion to the destination length. **Paste automation** keeps the original offsets from the section start. Matching lanes are replaced, and other lanes stay in place. Project **Undo** reverses either paste.

To transfer one curve, select its lane and click **Copy lane**. For a group of curves, open **Copy lanes…**, check the lanes you want, and click **Copy selected lanes**. Select the destination section and use either paste option. The paste preview shows the destination curve before you apply it. Only the copied lanes are replaced. **Mix** has separate bypass controls for drum effects and automated arrangement effects, plus a tempo-synced delay division.

Use **W** to save a record and its settings in the local crate. The crate stores references to source files and recordings. Mark several records to add them to a crate together. Use a `.flip` project when you want the source audio embedded.

For more obscure YouTube finds, combine a genre with **Decade** and **Max views**. A decade uses year or decade tags in the video title and skips unclear dates. The view cap uses YouTube's reported count and skips videos with no count available. Leave Max views blank for no limit. The studio shows the count at discovery.

Save frequently used search settings from **Filter presets**. For catalog-backed digging, expand **Discogs release filters** and fill in **Release year**, **Country**, or **Label**. The app checks release metadata in Discogs and searches YouTube for the tracks. The decade then checks catalog years; the view cap still checks YouTube. If Discogs requests authentication, set the `DISCOGS_TOKEN` environment variable to a personal access token and restart the app.

Use **Fill audition queue** to collect candidates without replacing the Studio track. In **Queue**, preview each candidate and mark it **Keep**, **Skip**, or **Later**. Open a candidate in Studio to start editing. Use the scrubber and preview length controls to audition a different passage, and enable level matching when comparing records. Mark several candidates to apply one verdict and undo it as a group. Queue decisions and heard sources persist locally. With the queue open, Up and Down move the audition focus, Space previews the focused track, Enter opens it, K/J/L mark it, and Z undoes the last decision.

Open **Queue → Taste profile** and turn on **Personalize queue** to rerank the pending tracks already in the queue. Move the slider from **Familiar** toward **Adventurous** to give more weight to variety. Each suggestion shows the indexed audio or catalog attributes that influenced it. Turn personalization off to compare with the original order. Dig filters and **Similar matches only** still control their own results.

The profile learns from explicit decisions while it is on. **Later** stays neutral. A **Skip** can lower similar tracks after two seconds of playback. Use **Skip with reason → Doesn’t fit this beat** to skip without teaching the profile a dislike, or choose **Dislike the sound** for a stronger signal. **Undo decision** restores the verdict and its feedback, even after reopening the app. **Reset feedback** clears the profile while retaining the queue decisions.

Open **Search → Files & tags** to browse audio by filename, title, tag, or duration without Python. Use **Add sample folder** to get started. **Index and model setup** also lets you add saved cuts and cached downloads, tag sources, and rescan files. Leave the query blank to browse, or enter terms such as `snare drums` to match a filename and a tag.

To search by sound, choose a Python environment, download the pinned model, and select **Resume CLAP indexing**. Enter a description in **Sound · CLAP**, or select a saved cut in Studio and choose **Find similar locally**. CLAP results show the original timestamp and a ranking score. Use **Filters** to narrow by source, duration, available tempo, or instrument tag. **Audition with beat** joins the current beat on a bar line. **Assign to pad** and **Save cut** copy the result into the project. **Remove from index** leaves original audio files in place. [CLAP setup and retrieval benchmark](workers/audio_analysis/README.md)

In Studio, **Suggest cuts** finds passages at the chosen length and emphasis. The sustained/tonal mode favors less transient passages. Select and save the ones you like. **Dig for similar** still ranks passages from new Dig results and shows matching timestamps in Queue.

In **Studio → Sample → Sample tools → Extract sound · Experimental**, mark a waveform selection between 0.10 and 6 seconds. Enter a description such as **bass guitar** and choose **Extract selection**. Compare **Original**, **Target**, and **Residual** from the same starting point. **Save target**, **Save residual**, and **Save both** add mono sources to the project. Save the `.flip` file to keep them. The experimental feature runs locally with SAM Audio Small and a CUDA GPU. [Windows setup](workers/audio_analysis/README.md#sam-audio-windows-feasibility-probe)

Choose **Export → DAW pack** in Studio to send an export folder to one or more saved destinations. Select the stereo mix, sample and drum buses, individual drums, separate pad and key parts, MIDI, and raw or processed cuts as needed. Choose the WAV settings and whether the stems bypass effects. The pack includes import instructions and a JSON manifest with tempo, section markers, source metadata, and pad mappings. Import rendered stems together at bar 1. Use **Export → WAV cut** to export just the selection or selected pad with the chosen audio format and optional pad processing.

| Key | Action |
| --- | --- |
| D / O / P | Dig / previous / next |
| F / W / S | Jump / save to crate / toggle studio |
| Space / Enter | Preview / play or stop the sequencer |
| Z / X / C | Set loop in / toggle loop / set loop out |
| B | Tap tempo |
| Backtick | Toggle computer keyboard performance mode |
| Ctrl+I / Ctrl+O / Ctrl+S | Import audio / open project / save project |

Pad keyboard mode uses `1 2 3 4`, `Q W E R`, `A S D F` and `Z X C V`. Arrow keys nudge the selected pad by 10 ms. Hold Shift to nudge by 100 ms.

YouTube Dig and **YouTube URL** use the [yt-dlp](https://github.com/yt-dlp/yt-dlp) beside the app or on your PATH, with its [YouTube JavaScript setup](https://github.com/yt-dlp/yt-dlp/wiki/EJS). Keep `yt-dlp.exe` beside the Windows release when moving it. yt-dlp can use FFmpeg to repair some audio containers. Imports are limited to videos up to 10 minutes and audio up to 64 MB. Imported audio is cached under `%LOCALAPPDATA%\Lost Samples Desktop\youtube` on Windows and can be reopened from your crate or history. To import a specific record, use **YouTube URL**. Timestamped links start at the linked point.

**Export loop WAV** and **Export pad WAV** save just that slice of the source as 24-bit audio at the original sample rate. **Estimate BPM** analyzes the selection if it is at least six seconds long, or the source otherwise. It estimates tempos from 60 to 180 BPM. Open a candidate tempo to audition its beat grid against the source or apply it. Use **Tap** for tracks without a steady beat.

Commons recordings link to their source pages for attribution and license details. Projects, crates, and exports are local. The YouTube and waveform workflow draws on [Tubetape](https://github.com/DocDamage/tubetape) and [CrateDigger](https://github.com/DocDamage/old-cratedigger).
